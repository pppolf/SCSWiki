# 保研（推荐免试研究生）

本页面涉及推荐免试研究生政策、成绩计算、资格条件、材料要求和时间节点，属于高风险流程类内容。补充具体信息前，应优先引用学校或学院公开发布的正式通知。

## 政策文件

按照《西华师范大学推荐优秀应届本科毕业生免试攻读硕士研究生工作实施办法》（附件1）、《西华师范大学2026年“农村学校教育硕士师资培养计划”专项推荐工作办法》（附件2）等相关文件的精神和要求，切实提高推免选拔质量，确保推免工作公平公正，结合学院实际，特制定《西华师范大学计算机学院推荐2026届优秀应届本科毕业生免试攻读硕士研究生工作实施细则》。

### 基本条件

推免生基本条件需满足[《西华师范大学推荐优秀应届本科毕业生免试攻读硕士研究生工作实施办法（2025年修订稿）》第九条](https://jwc.cwnu.edu.cn/info/1137/68704.htm)。

### 总评成绩计算办法

推免生成绩计算按照《西华师范大学推荐优秀应届本科毕业生免试攻读硕士研究生工作实施办法（2025年修订稿）》第三章执行。

### 工作程序及日程安排

（一）学生报名及材料提交

在2025年9月8日上午9点之前，符合申请条件的学生将《西华师范大学推免生报名申请表》、《西华师范大学拟推免学生名单汇总表》、《西华师范大学计算机学院加分项汇总表》以及各类支撑材料原件及复印件提交给班主任，由班主任汇总以后提交给沈雪珍老师。

备注：1.逾期未报名、未提交、漏提交材料，责任自负；2.推免研究生申请与研究生支教团申请不得重复。

（二）资格审查、材料鉴定及拟推免学生名单确定

学院推免工作小组对提交推免报名申请表的学生进行资格审查，对学生提交的材料依据《西华师范大学推荐优秀应届本科毕业生免试攻读硕士研究生工作实施办法（2025年修订稿）》，由推免专家审核小组分别对成绩类材料、学术特长材料、学科竞赛材料、社会服务材料按类别进行复查审核。

（三）公示

在学生对审核结果确认后，推免工作小组根据学校公布的推免指标，按照各专业学生总评成绩从高到低的顺序，确定学院拟推免名单，并在学院官网进行公示，学生如有异议在公示期间向学院反映。

（四）拟推免名单上报学校

公示结束无异议后，学院向学校推免工作领导小组办公室上报推免名单。

备注：学生未对审核结果签字确认，责任自负。

### 名额分配

（一）计算机科学与技术专业（师范）6名；

（二）软件工程专业9名；

（三）网络空间安全专业3名；

（四）研究生支教团推荐2名。

备注：研究生支教团选拔按校团委方案执行,相关工作由学院团委另行[通知](https://youth.cwnu.edu.cn/info/1227/16719.htm)；

### 纪律监督

纪律监督小组负责对学院推免工作进行全程监督。
