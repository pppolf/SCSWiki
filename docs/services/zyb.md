# 卓越班

> 此内容来自：计算机学院2026年“网鼎卓越”卓越班遴选报名通知，由于是以前通知，故所有涉及隐私号码都使用xxx处理

## 项目背景

贯彻落实《教育强国建设规划纲要(2024-2035)》，深化“四新”建设，强化科技教育与人文教育协同发展，探索拔尖创新人才培养新模式，培养具有复杂系统研发能力和国际视野的网络空间安全领军人才。

## 选拔办法

（一）选拔对象

1.2025级全日制本科生，选拔人数为30人。

2.以特殊需求预科招录的学生、公费师范生、优师专项等享受特殊招生政策的学生，不得跨专业参加本项目遴选。

3.已经完成1次转专业的学生，不得参加本项目遴选。

（二）选拔条件

1.思想政治‌

热爱社会主义祖国，拥护中国共产党的领导；遵守宪法和法律，遵守校纪校规；诚实守信、学风端正、积极向上、品行优良，无任何违法违纪受处分记录（包括学术不端、考试作弊等）；操行加分不低于6分，扣分不超过5分。

2.学业表现

学习成绩优良，2025-2026学年第一学期必修课程全部通过，无挂科记录，年级排名前40%。

### 选拔程序

1.报名：凡符合条件者均可报名。请有意报名的同学提交《计算机学院“信息科技卓越教师班”报名申请表》（附件一），于2026年6月4日18:00之前发送到xxx@qq.com邮箱,报名成功请加QQ群：xxx，群备注名请修改为：学号+姓名。纸质版附件一、成绩单、家长签名同意书、获奖证明材料，于2026年6月4日18:00之前交到理科楼B403。

2.笔试

时间：6月5日

内容：网络空间安全专业基础知识

3.面试

时间：6月5日

内容：沟通能力、职业规划、综合素质、团队协作

（具体笔试、面试时间及地点见群通知）

4.成绩汇总与公示

综合成绩=笔试成绩\*45%+面试成绩\*45%+附加分（10分）。其中附加分只计算专业类赛事获奖（三等奖以上）与双创类赛事获奖（三等奖以上）；团体赛事，院校级只统计第一获奖人，省级统计前三获奖人，国家级统计前四获奖人；院校级奖项记0.5分，省级奖项记1分，国家级奖项记2分，同一赛事只统计最高奖项；附加分总计累加不超过10分。成绩汇总在学院主页公示3个工作日，公示期为6月6—9日。公示期内主动放弃资格者，按总成绩排名顺延补录。

### 培养特色

1.课程设置：根据“网鼎卓越”卓越人才培养班培养目标的要求新增《WEB安全与防护》、《逆向工程》、《电子取证》等前沿能力课程，与《漏洞复现与代码审计》、《内网渗透高级实践》、《Python安全工具开发》等核心实践课程。

2.师资配备：校内前沿理论导师+企业工程师实践导师双导师制。

3.动态退出：每学期末进行综合评定，连续两学期排名后10%者强制退出；考试作弊、学术不端等违反学管理条例行为强制退出。

4.激励机制：学院对评优评奖、保研名额进行倾斜（以每年学院学生总人数动态调整）；推荐进入学院科研实验室；由校友会基金设立额外奖助学金。
