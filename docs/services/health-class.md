# 体育课转修保健课

> 当前仅收录一份离线流转的空白申请表，没有找到可公开访问的学校原始下载链接，也无法确认
> 表格的制发时间和当前有效性。使用前请向学院或相关管理部门核实最新表格与办理要求。

## 空白申请表

表格标题为《学生体育课转修保健课申请表》，包含学生基本信息、转修原因与相关材料说明，
以及校医院、体育学院和教务处意见栏。下半部分附有《学生体育课转修保健通知》。

[预览或下载《体育课转修保健课申请表》](/services/health-class-transfer-application.pdf)

## 使用与隐私提醒

- 本站只提供空白表格，不据此推断当前办理顺序、材料要求、受理时间或地点。
- 填表后可能包含姓名、学号和健康状况等个人信息，请勿将填写后的版本上传到公开仓库或公开群聊。
- 提交前应确认当前学期是否仍使用此版本，以及是否需要补充诊断证明等材料。
- PDF 由原 `.doc` 文件按原版式转换，并已清除作者和创建软件等文件元数据。
