# 科研与实验室总览

本页只记录本科生接触科研和实验室的通用准备方向，不发布具体实验室、教师、招收要求、考核方式或联系方式。学院实验室和科研团队的公开信息，请以学院官网和相关通知为准。

## 为什么提前了解科研

- 科研训练能加深对课程知识的理解，也是升学（保研、考研复试）和求职的重要加分项。
- 参与实验室项目可以提前接触真实问题、工具链和团队协作方式。
- 提前了解方向，可以在选课、竞赛和项目实践中更有针对性。

## 通用准备方向

- **打牢基础**：数据结构、算法、数学和英语是多数科研方向的共同基础。
- **多读公开资料**：教材、公开课、综述文章和开源项目文档都是低成本入门途径。
- **动手实践**：课程设计、学科竞赛（见[学科竞赛](/competitions/)）和开源贡献都能积累可描述的项目经历。
- **记录过程**：保留项目背景、方法和结果的公开可描述部分，方便日后整理进简历或个人主页。
- **保护隐私**：不公开未发表成果、内部数据和个人身份信息。

## 关于实验室信息

学院具体实验室、科研团队和招收安排属于学校特定信息，需要以公开正式来源为准。整理实验室信息时，请使用[科研与实验室信息模板](/research/lab-template)，补充内容前先确认来源公开、不包含个人隐私和内部信息。

## 待补充方向

以上方向缺少可靠公开来源时，只保留为待核验模板，不写成确定事实。
