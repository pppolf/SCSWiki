# 2026 级新生报到

::: warning 先核对录取材料
本专题根据随 2026 级本科录取通知书发放的新生材料整理。招生信息网当前公开的“新生入学须知”尚未提供 2026 级网页版本，因此除已单独列出公开来源的内容外，其余学校流程仍处于待核验状态。

如本专题与录取通知书、易班智慧迎新、学校或学院最新通知不一致，以最新正式通知为准。
:::

## 关键时间

| 时间                     | 事项                                 | 核验情况                               |
| ------------------------ | ------------------------------------ | -------------------------------------- |
| 预计 2026-09-01 起       | 新生学杂费缴费渠道开放               | 计划财务处已公开说明                   |
| 报到前两周起             | 易班“校方认证”预计可以办理           | 见录取材料，仍需以系统实际开放时间为准 |
| 2026-09-10 至 2026-09-11 | 2026 级本科新生报到                  | 见录取材料，报到前再次核对             |
| 集中报到后一个月内       | 新生团员在“智慧团建”完成组织关系转接 | 见录取材料，按学院团委通知办理         |
| 2026-09-30 前            | 补交通过审核后的户口迁移材料         | 仅适用于自愿迁户口且现场未办结的同学   |

## 报到前准备清单

1. 完成[易班网上迎新](/start/online-registration)，填写到校交通方式和时间。
2. 确认学籍档案、党团组织关系和户口是否需要办理，查看[档案、组织关系与户口](/start/records-and-household)。
3. 查看[学杂费缴费](/start/payment)。已办理助学贷款的同学不要重复缴费。
4. 家庭经济困难或需要贷款的同学提前查看[学生资助与助学贷款](/start/financial-aid)。
5. 决定自带还是自愿购买卧具，核对[住宿物品与军训服装](/start/accommodation)。
6. 出发前阅读[报到安全](/start/arrival-safety)，不要通过陌生链接缴费或向他人交出证件。

## 信息冲突时怎么处理

按以下顺序核对，不要只依据截图、群聊转发或往年经验：

1. 本人收到的 2026 级录取通知书及随附材料；
2. 易班“西华师范大学智慧迎新”和学校智慧校园信息门户；
3. 学校、学院相关部门官网发布的当年通知；
4. SCSWiki 的整理内容。
