# 军训专题

> 本页收录的是 2025 级新生军训资料，只适用于对应年份。后续年级的训练时间、地点、
> 管理要求、考核办法和联系方式均可能调整，请以学校当年正式通知为准。

## 2025 级新生军训手册

手册封面标注由西华师范大学人民武装部印制，内容包括军训工作文件、安全与卫生要求、
考核办法、作息安排、请假申请表、军事法规和队列动作要领等，共 89 页。

[预览或下载《军训手册 2025（隐私处理版）》](/start/military-training-handbook-2025-privacy-clean.pdf)

### 公开版处理说明

- 原手册中的医务工作联系电话、工作人员通讯录，以及含姓名和联系电话的安排表页面，
  已替换为隐私处理说明页；其余页面保持原版内容。
- PDF 的作者、创建软件和修改时间等文件元数据已清除。
- 当前没有可公开访问的学校原始下载链接，因此本页保持“待核验”状态。
- 手册中涉及的时间、流程、纪律、成绩评定和表格均按 2025 年资料理解，不应直接套用于其他年份。
