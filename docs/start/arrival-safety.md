# 新生报到安全

本页把 2026 级录取材料中的安全须知按场景重新整理。校内接站安排、报警电话和管理要求可能调整，出发前应再看学校最新通知。

## 赴校途中

- 选择正规交通工具，不轻易搭乘陌生人的便车或未经学校确认的接站车辆。
- 在车站、码头等人员密集场所看管好手机、电脑、证件和行李，不与陌生人交换或代管贵重物品。
- 不吃陌生人提供的食物或饮料；需要过夜时选择正规、治安条件可靠的住宿场所。
- 不随身携带大量现金，银行卡和身份证分开保管，不向任何人透露密码或验证码。
- 不携带易燃易爆物品、管制刀具或其他违禁物品。
- 对“老乡”“学长”“接站老师”等身份保持核验意识，遇到借钱、借手机或代办业务的请求先拒绝。

## 报到现场

- 学校志愿者和工作人员应有工作标牌。身份无法确认时，直接去正式报到点询问。
- 不把现金、银行卡、身份证、录取通知书或档案交给非指定工作人员。
- 学校没有“必须先购买电话卡才能报到”的要求，也不要相信以学校部门名义收取会员费或服务费的人员。
- 缴费只使用[学校官方缴费渠道](/start/payment)，不要点击陌生链接或向私人账户转账。
- 到食堂等正规场所就餐，避免卫生状况不明的流动摊点。

## 宿舍安全

- 不让陌生人进入寝室，拒绝上门推销商品、办卡或发展会员。
- 家长和其他陪同人员不能在学生公寓留宿。
- 最后一位离开寝室的同学应关好门窗，并关闭不需要使用的水、电设备。
- 禁止私接电线、使用“热得快”等违规或劣质电器、在宿舍使用明火或乱扔烟头。
- 不熟悉周边环境时避免单独远行，夜间提前返校，不在校外随意留宿。
- 注意校内道路车辆，保管好手机、电脑等贵重物品。

## 遇到危险或诈骗

有现实人身危险时立即拨打 **110**，并向现场工作人员或学校保卫部门求助。校内各校区报警电话请从录取材料、校园现场标识或保卫部门最新公告中核对，本站不转载可能变更的号码。
