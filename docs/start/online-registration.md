# 易班网上迎新

2026 级录取材料要求，新生在入校前通过易班进入“西华师范大学智慧迎新”，完成入学相关事项。具体开放时间和页面名称以易班内实际显示为准。

## 办理步骤

1. 从正规应用商店下载易班 App，或访问[易班官网](https://www.yiban.cn/)。
2. 使用本人手机号注册，在认证流程中选择“西华师范大学”，按系统要求填写真实姓名和学号。
3. 完成“校方认证”。手机号注册不受时间限制，但录取材料说明校方认证通常在报到前两周开放。
4. 进入“西华师范大学·易班”首页，打开“西华师范大学智慧迎新”。
5. 按系统提示查询班级和学号、预填写新生信息、了解辅导员信息，并登记到校交通方式和时间。
6. 留意校内推送，按要求加入“西华师范大学 2026 级新生入学教育”课程，完成线上学习和考试。

已有易班账号的同学，可在 App 内选择“重新认证”，再按系统提示填写学校和学籍信息。

## 使用时注意

- 本页不收录新生群号或个人联系方式。遇到问题时，通过易班内的学校工作站入口、学生工作部官网或学院正式渠道咨询。
- 不要把验证码、身份证照片、录取通知书编号或账号密码发给所谓“迎新工作人员”。
- “校方认证”尚未开放时，不要反复注册新账号，先等待系统开放并核对姓名、证件和学号是否一致。
- 报到日期见[2026 级新生报到](/start/)。
