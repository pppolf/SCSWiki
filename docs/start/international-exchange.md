:::

## 申请前要确认

根据学校公开的交流学习管理办法，学生通常需要关注：

- 是否为学校全日制在籍学生，成绩、外语水平和在校表现是否满足项目要求；
- 项目是否经过国际合作与交流处或学院正式发布、审核和备案；
- 课程能否认定学分，是否与校内考试、实习或毕业安排冲突；
- 学费、旅费、住宿、生活、保险等费用由谁承担；
- 报名、学院推荐、学校审核、外方录取、行前教育和返校报到等流程。

查询最新项目时，请直接访问[国际合作与交流处学生出国项目](https://fao.cwnu.edu.cn/cgxm/xscg.htm)。本站不转载工作人员个人联系方式。
