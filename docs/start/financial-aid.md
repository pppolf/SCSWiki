# 学生资助与助学贷款

::: warning 适用范围
国家资助标准以国家最新政策为准；四川省分档、学校是否开办校园地贷款、承办银行、申请日期和校内办理流程来自 2026 级录取材料，尚需以当年系统和学校通知再次核对。
:::

## 新生先做什么

- 暂时筹不齐学费和住宿费：报到时申请“绿色通道”，先办理入学手续，入学后再完成家庭经济困难认定。
- 准备申请家庭经济困难认定：如实填写随录取通知书发放的申请表，作出个人承诺并签字；表格不要求另行盖章。属于低保、特困供养等情形的，可携带相关证明材料复印件。
- 已办理生源地助学贷款：保存受理证明、回执或入学验证码，报到后尽快到学校资助办理点完成确认，不要重复缴纳同一笔学费和住宿费。
- 提前办理并激活本人社会保障卡。四川省发放到学生个人的国家资助资金使用社会保障卡“一卡通”；省外学生办卡时可优先咨询国有银行网点。

## 资助项目一览

| 项目                           | 2026 级录取材料中的主要范围和标准                                                                              |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| 国家奖学金                     | 二年级及以上特别优秀的全日制本专科生，每生每年 10,000 元                                                       |
| 国家励志奖学金                 | 二年级及以上品学兼优的家庭经济困难全日制本专科生，每生每年 6,000 元                                            |
| 国家助学金                     | 家庭经济困难全日制本专科生平均每生每年 3,700 元；四川省材料列为 4,900、3,700、2,500 元三档                     |
| 退役士兵国家助学金             | 全日制在校退役士兵学生每生每年 3,700 元                                                                        |
| 国家助学贷款                   | 本专科生每人每年最高 20,000 元，优先支付学费和住宿费，余款可补充生活费                                         |
| 服兵役高等学校学生国家教育资助 | 学费补偿、贷款代偿或学费减免，本专科生每人每年最高 20,000 元                                                   |
| 四川省基层就业学费奖补         | 省属高校应届毕业生到艰苦边远地区基层单位连续服务满 3 年，材料列示每生每年不超过 6,000 元                       |
| 公费师范生、优师计划           | 在校期间免缴学费和住宿费，并可获得生活费补助                                                                   |
| 滋蕙计划                       | 家庭经济特别困难的大一新生可在高中或户籍地资助中心申请；省内院校录取一次性 500 元，省外院校录取一次性 1,000 元 |
| 筑梦奖学金                     | 品学兼优且曾获得国家开发银行助学贷款的学生，每生每年 4,000 元                                                  |
| 勤工助学                       | 在学校组织下利用课余时间参加工作并取得合法报酬，具体岗位和申请时间以校内通知为准                               |
| 绿色通道                       | 家庭经济特别困难的新生可先办理入学，之后再由学校认定困难情况并安排相应资助                                     |
| 校内资助                       | 包括校内奖助学金、临时困难补助、学费减免和社会捐助项目等                                                       |

国家奖学金与国家励志奖学金不能在同一学年同时获得，但符合条件的学生可以同时申请国家助学金。学校奖助学金的当年评审条件、流程和公示要求见[奖助学金](/services/scholarship)。

## 国家助学贷款

### 类型和学校安排

国家助学贷款分为生源地信用助学贷款和校园地国家助学贷款，同一学年只能选择其中一种。2026 级录取材料说明，学校目前暂未开办校园地国家助学贷款，新生主要在户籍所在地办理生源地信用助学贷款。

材料列出的承办银行为：

- 国家开发银行；
- 四川农商联合银行；
- 中国银行。

生源地贷款通常在 6 月至 10 月办理，2026 级材料列出的三家银行办理期均为 **6 月 15 日至 10 月 31 日**。各地受理安排可能不同，应以户籍地县级学生资助管理中心和银行系统显示为准。

### 基本申请条件

申请人通常需要满足以下条件：

1. 具有中华人民共和国国籍；
2. 诚实守信、遵纪守法；
3. 已被符合国家规定的高校正式录取，持有真实、合法、有效的录取通知书，或为符合条件的在校生；
4. 家庭经济困难，家庭收入不足以承担完成学业所需的基本费用；
5. 办理生源地信用助学贷款时，学生本人入学前户籍和共同借款人户籍符合当地要求。

### 贷款额度、期限和利率

- 全日制普通本专科学生每人每年最高不超过 **20,000 元**。
- 贷款期限为学制加 15 年，最长不超过 22 年；符合条件时可有最长 60 个月的还本宽限期。
- 在校期间利息由财政全额补贴，毕业后的利息和本金按合同约定承担。
- 利率按同期同档次贷款市场报价利率减 70 个基点执行，即 `LPR - 0.7%`。本站不保存会随月份变化的 LPR 示例值。

### 办理流程概览

#### 国家开发银行

- 首次贷款通常由学生与共同借款人携带身份证、户口簿、录取通知书等材料，到户籍地县级学生资助管理中心现场办理。
- 未通过预申请的学生还需要按系统要求提交家庭经济困难学生认定材料。
- 续贷一般可通过国家助学贷款 App 或学生在线系统远程申请。
- 到校后按要求提交受理证明或回执校验信息，由学校录入回执；录取材料要求在到校后 15 日内完成。

#### 四川农商联合银行

- 通过四川农商银行个人手机银行的“生源地信用助学贷款”入口申请，按实际情况选择首次申请或续贷。
- 首贷需要共同借款人完成授权，审批后在线签订合同。
- 省内高校学生到校后，由学校经办人员按银行流程完成报到确认；随后在银行 App 中查看放款和缴费进度。

#### 中国银行

- 在中国银行手机银行进入国家助学贷款申请，选择正确的户籍地资助中心。
- 按系统要求上传本人、共同借款人相关证件和录取通知书，双方完成信息确认及合同签署。
- 生成入学验证码后，到校交由学校资助中心完成入学确认。

银行 App 的界面、材料清单和认证方式可能更新，操作前应查看银行及户籍地资助中心的当年说明。

## 到校确认与缴费

- 携带贷款受理证明、回执校验码或入学验证码，到学校大学生资助管理中心办理确认。
- 贷款转入学校前，缴费系统显示欠费通常不代表贷款失败。不要自行重复缴费。
- 国家开发银行贷款到款时间可能较晚；计划财务处 2026 年指南预计 11 月起陆续处理。
- 四川农商联合银行贷款可能需要本人在 App 中执行缴费。学校账户和汇款备注必须从银行流程或计划财务处官方页面获取。
- 本站不转载学校银行账号、经办人姓名和联系电话，避免过期信息或仿冒页面被用于错误汇款。

## 防诈骗

- 国家助学贷款是信用贷款，不需要中介代办，也不需要缴纳“保证金”或“解冻费”。
- 不把身份证、社保卡、银行卡、验证码或人脸认证交给他人操作。
- 对冒充老师、资助机构或银行人员的短信、电话和好友申请保持警惕。
- 政策和办理入口优先从[全国学生资助管理中心](https://www.xszz.edu.cn/)及[四川学生资助网](https://www.scxszz.cn/)核对。
