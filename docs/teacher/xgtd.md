# 学工团队

本页整理计算机学院学工团队公开简介，便于同学了解学生工作、团学工作、就业创业指导和思想政治教育等相关老师。人员分工和负责年级可能随学年调整，具体事务请以学院最新通知为准。

> 本页不展示办公电话、邮箱、通讯地址等个人联系方式。需要联系老师时，请以学院官网公开页面或学院正式通知为准。
